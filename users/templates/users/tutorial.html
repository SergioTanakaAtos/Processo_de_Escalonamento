Como se cadastrar no Sistema de Escalonamento?

• O campo e-mail deverá aceitar apenas e-mails com o domínio ATOS, exemplo: @atos.net; Todo o conteúdo escrito antes do @ será o seu usuário para login.

• A senha deve possuir caracteres especiais #@!$%*, letras maiúsculas, minúsculas e números. A senha não deve ser parecida com o seu user ou e-mail;

• Confirme a senha para prosseguir e autenticar;

• O campo Permissões permite que você selecione os grupos necessários para consultar e utilizar os escalonamentos. Após o seu cadastro, as permissões solicitadas serão enviadas para o administrador, que decidirá se aceita ou recusa o seu pedido. Enquanto a decisão não é tomada, sua solicitação permanecerá pendente.

Verifique com atenção os grupos selecionados para assegurar que atendem às suas necessidades. Se precisar de ajustes nas permissões, entre em contato com o administrador.

Funcionalidades de usuários em Tabela de Dados

Ações disponíveis para Staff e Administradores

1. Adicionar Novas Empresas:
Staff e administradores têm permissão para adicionar novas empresas ao sistema.
2. Upload de dados via planilha XLSX:
Esses usuários podem fazer o upload de dados de uma planilha no formato XLSX para o sistema.
Acesso a todos os escalonamentos:
Tanto staff quanto administradores possuem acesso total a todos os escalonamentos disponíveis no sistema.

Para garantir que o upload da planilha de escalonamento seja realizado com sucesso, é fundamental que a coluna "Informações" esteja na primeira posição. Caso contrário, o sistema pode apresentar erros de leitura durante o processamento do arquivo.

Solicitação de acesso para outros usuários

Solicitação de acesso ao Escalonamento:

Usuários que não têm acesso a um escalonamento específico podem clicar no botão "Solicitar" para enviar um pedido ao administrador. O administrador analisará a solicitação e decidirá se concede ou recusa o acesso. Se aprovado, o usuário obterá permissão para acessar o escalonamento solicitado. Se recusado, o usuário será notificado e poderá buscar mais informações ou fazer novas solicitações.

Interface de Escalonamento

A interface de escalonamento refere-se aos níveis de escalação de uma determinada empresa. Somente usuários com permissões de staff ou superuser terão acesso às seguintes funcionalidades:

• Adicionar ou editar escalonamento;
• Visualizar a quantidade de vezes que uma escalação foi utilizada no dia.

A função "Usou?" é utilizada para indicar quando uma escalação foi usada para resolver um incidente ou problema.

Controle de Acesso

A interface de controle de acesso exibe todos os usuários do sistema, exceto os superusers. As funcionalidades incluem:

Ver acessos: Ao clicar nesta opção, são exibidas as informações do usuário, se ele é um staff e quais empresas ele tem acesso. É possível:
• Editar os acessos e o nível do usuário.
• Se o usuário for staff, ele terá acesso a todas as empresas.
• Se for um usuário comum, poderá ser removido ou ter acesso concedido às empresas disponíveis.

Permissões de usuários

A interface de permissões organiza as solicitações de acesso por usuário. Ao clicar no nome de um usuário, você pode visualizar as empresas para as quais ele solicitou acesso. As ações disponíveis são:

• Confirmar: Aprovar a solicitação, concedendo ao usuário permissão para visualizar e interagir com as empresas selecionadas.
• Recusar: Negar a solicitação, mantendo o usuário sem acesso às empresas solicitadas;

Além disso, usuários com o perfil de Staff têm acesso completo a todas as empresas e suas funcionalidades.
